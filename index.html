01. Sobre mí

Soy Matías Pirrone, programador junior con formación en Desarrollo de Aplicaciones Multiplataforma (DAM) por el CIFP Federica Montseny (Madrid). Mi Trabajo Fin de Grado fue una aplicación Android nativa completa desarrollada extremo a extremo: cliente móvil en Java, backend con JDBC, base de datos MySQL y despliegue sobre un servidor Linux propio en OVH con SSH, UFW y Fail2Ban.

Estoy certificado en Claude Code in Action por Anthropic y utilizo la IA como amplificador de productividad en mi día a día: hooks personalizados, integración de MCPs y construcción de agentes con el Claude Agent SDK. Creo firmemente que el desarrollo moderno consiste en combinar el criterio humano con la capacidad de la IA, y en aprender rápido cuando el proyecto lo requiere. Inglés B2 (comprensión técnica), carnet B de conducir y ciudadanía italiana (UE sin restricciones).

Mi base principal es Java con Spring Boot. También trabajo con Python y FastAPI para proyectos con integración directa a LLMs.

Mi primera oportunidad como desarrollador backend, full-stack junior o consultor IT junior con foco en IA. Madrid, presencial, híbrido o remoto.

Certificación oficial Claude Code in Action de Anthropic + proyectos propios en producción con integración real de IA. Dos stacks backend en paralelo: Java 21 con Spring Boot (mi base principal) y Python 3.14 con FastAPI, cada uno con su proyecto público en GitHub, tests automatizados, Docker y CI/CD. No solo "sé programar": construyo APIs completas y las publico.

Porque es donde más multiplico mi productividad y donde está la ventaja competitiva ahora mismo. Uso Claude Code a diario como amplificador, no como sustituto del criterio humano.

AWS Cloud Practitioner para añadir cloud al stack. Próximos pasos: profundizar en RAG, LangChain y bases vectoriales como Qdrant o pgvector.

03. Proyectos

Proyecto individual · Noviembre 2026

rag-aws-notes · Python + ChromaDB + Claude API

Mini-RAG sobre apuntes de AWS Cloud Practitioner con búsqueda semántica local y Claude para generar respuestas

Pipeline completa de Retrieval-Augmented Generation construida sobre mis propios apuntes del curso AWS Cloud Practitioner. Ingesta por secciones H2/H3 con ventanas de 100 tokens y solape, embeddings multilingües con sentence-transformers, persistencia local en ChromaDB con distancia coseno, y generación con Claude Sonnet 5.5 citando la sección de origen de cada chunk.

Diseño robusto: cuando el contexto recuperado no cubre la pregunta, el sistema lo dice en vez de inventar. CLI, API FastAPI con endpoint GET /ask, y README con arquitectura, 9 casos reales de troubleshooting documentados y ejemplo de output.

Python 3.14 ChromaDB sentence-transformers Anthropic SDK claude-sonnet-5-5 FastAPI RAG Vector Database Prompt Engineering

Proyecto individual · Octubre 2026

Task Manager API · Python + Claude AI

REST API con FastAPI, PostgreSQL dockerizado, CI/CD y endpoint integrado con la API de Anthropic

API REST completa en Python 3.14 construida con FastAPI y arquitectura en capas (endpoints, repository, models, infraestructura) siguiendo principios SOLID.
